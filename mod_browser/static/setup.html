Set up the game

On your computer, once. Server address {{address}}.

With the CurseForge app (easiest)

  1. Download the pack. Download for CurseForge
  2. Import it. In the CurseForge app open Minecraft, choose Create Custom Profile, then Import (beside the Create button), and pick the zip. The app downloads every mod itself, Loconautics included.
  3. Play the new profile and join {{address}} from Multiplayer.

When the pack changes, download it again and import it the same way (delete the old profile first). The check at the bottom of this page tells you whether it changed.

With Prism Launcher (updates itself)

  1. Install Prism Launcher from prismlauncher.org and sign in with your Minecraft account.
  2. Download the instance. Download for Prism
  3. Import it. In Prism choose Add Instance, then Import, then pick the zip you just downloaded. Prism will offer to download Java 21 if you do not have it: say yes.
  4. Launch it. The first launch downloads the mods (a few minutes). Every launch after that updates them to match the server, so you never fail a login over a mismatch.
  5. Join {{address}} from Multiplayer.

Prism only: mods you download by hand

The authors of these mods do not allow other launchers to download them. The first launch will stop and name each one: open its page, download the file named below, and put it in the folder the launcher shows. You only do this once per mod.
